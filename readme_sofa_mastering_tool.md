# SOFA Mastering & DFHRTF Tool (removed)

> The standalone SOFA Mastering Tool (`_sofa_mastering_tool.py`) is deprecated and is no longer included in Mesh2SOFA. Please use **SOFA Buddy** instead: it is actively maintained and has much improved functionality. [https://github.com/variancelog/SOFABuddy](https://github.com/variancelog/SOFABuddy)

Nothing changes inside Mesh2SOFA: **7. Generate Mastered SOFA Files** and **Generate DFHRTF Files** in the main GUI never used the standalone tool and work as before.

The last version of the tool is in the repository history (v1.8.3) if you still need it.
